# Code of conduct

Be respectful. Disagree with ideas, not people. Harassment, personal attacks and discrimination are not welcome in issues, pull requests or discussions.

Maintainers may edit or remove comments and block people who break these rules. To report a problem, contact the maintainer, Bradley Odimmasi, through a private [security advisory](https://github.com/KshRaven/runlytics/security/advisories/new) or the email on the GitHub profile.
