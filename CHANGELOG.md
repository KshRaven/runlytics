# Changelog

## Unreleased

## 0.2.0
- Added project distribution metadata, including source, documentation, issue, and changelog URLs, and the Python 3.14 classifier.
- Expanded continuous integration across Linux, Windows, and macOS, and added a package-build artifact job.
- Added a tag-triggered GitHub release workflow that validates the version, reruns checks, builds distributions, creates release notes from this changelog, and publishes to PyPI.
- Added repository contribution resources, including issue and pull request templates, support information, conduct and security policies, and Dependabot configuration.
- Updated README links to absolute repository URLs and added license and author information.
- Cleaned package and test imports and typing, and updated the Ruff configuration.

## 0.1.0
- First public version: dashboard, SummaryWriter, CLI, lazy store and the packaging scripts.
